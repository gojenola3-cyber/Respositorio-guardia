# Estimación de costes

Precios consultados en octubre de 2026. Parte de las fuentes son de terceros: **comprueba la página oficial de cada proveedor antes de contratar.** No hay coste por usuario: el coste es de infraestructura y no crece por número de voluntarios hasta volúmenes muy superiores a los de una organización local.

## Mensual

| Concepto | Opción mínima | Recomendado para operar | Notas |
| --- | --- | --- | --- |
| Supabase | Free: 0 € | **Pro: ~25 $/mes** | El plan Free pausa el proyecto tras ~7 días sin actividad: **inaceptable para emergencias**. Pro no se pausa e incluye copias diarias. |
| Expo Push | 0 € | 0 € | Expo indica que el servicio push no tiene coste. Límite de 600 notificaciones/s por proyecto. |
| EAS Build | Free (builds limitados al mes, en cola) | Free o de pago si se compila a menudo | Se puede compilar en local con Xcode y Android Studio. |
| Panel web | 0 € (si las condiciones del plan gratuito lo permiten) | 0-20 $/mes | Vercel Hobby es para uso no comercial: revisar. |
| Teselas de mapa | 0 € dentro del cupo gratuito de un proveedor | 0-10 $/mes | Uso bajo: solo el panel de responsables. |
| Correo transaccional (SMTP) | Cupo gratuito de un proveedor | 0-10 $/mes | Invitaciones y recuperación de acceso. |
| Dominio | ~1 €/mes | ~1 €/mes | |
| **Total** | **≈ 0-1 €/mes (solo pruebas)** | **≈ 25-45 $/mes** | |

## Costes que no son de software

- Pruebas operativas con dispositivos reales de varios fabricantes.
- Revisión jurídica (RGPD, EIPD).
- Mantenimiento: actualizar Expo SDK y dependencias cada pocos meses. Las tiendas exigen SDK recientes.
